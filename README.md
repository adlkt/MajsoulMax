# 雀魂 MAX

基于 mitmproxy 的雀魂角色、皮肤和装扮改包工具，工作分支为 `dev`。

流量接管和出站路由统一由 Clash Verge 负责。

启动时显示更新检查、版本、插件及配置加载结果和监听地址；实际更新、新版本、警告和错误仍会显示。逐条游戏消息、小助手发送成功、资源替换及牌谱玩家详情仅在 DEBUG 级别显示。消息日志只记录方向、方法名、处理状态和长度，不输出完整数据。

使用前请在 Clash Verge 中启用 TUN 并加载 `clash-verge.js`。

有游戏流量时约每 10 秒输出一条汇总，例如 `延迟 86ms | ↑2包 ↓2包 | 80B`，显示 RPC 平均延迟、收发包数和区间总流量。统计覆盖捕获到的非注入 WebSocket 消息，大小为改包前的消息内容字节数，不含协议开销。延迟包含服务器处理时间，没有匹配响应时显示 `--`。空闲期间不刷屏，下一条游戏消息到达时汇总累计区间。

排查问题时可临时开启调试日志：

```sh
MAJSOUL_LOG_LEVEL=DEBUG ./start.sh
```
